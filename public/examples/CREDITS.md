# Example songs: sources and licences

The MIDI files here are unchanged copies of files from the [Mutopia Project](https://www.mutopiaproject.org),
renamed. GuitarTab turns them into tablature when they are opened (Example songs in the File menu);
the list, with the same credits, is `src/data/exampleSongs.ts`. The two band songs, "Open Road" and
"Back Porch Shuffle", are written for GuitarTab and built in code (`src/data/demoArrangement.ts`,
`src/data/exampleShuffle.ts`).
